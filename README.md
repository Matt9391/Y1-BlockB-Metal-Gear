# buz

A template to build games in C++. Your game derives one class from
`buz::game`, which the engine drives; the engine handles the main loop,
rendering, input and asset loading. It runs on Windows and Linux and draws with OpenGL, or with DirectX
12 (Windows) or Vulkan (Linux) when you pick the DirectX 12 or Vulkan preset.

## Requirements

**Windows**: Visual Studio 2026 with the *Desktop development with C++*
workload. That workload also installs the Windows SDK and CMake, so there is
nothing else to install: `generate.bat` finds the CMake that comes with Visual
Studio on its own.

**Linux**: a C++20 compiler (GCC 13 or Clang 17 or newer), CMake 3.25+, Ninja,
a graphics driver with OpenGL 3.3 (or Vulkan 1.3 for the Vulkan preset), and
the development headers SDL needs to open a window. On Ubuntu or Debian:

```
sudo apt install build-essential cmake ninja-build pkg-config \
    libx11-dev libxext-dev libxrandr-dev libxcursor-dev libxfixes-dev libxi-dev \
    libxss-dev libxtst-dev libxkbcommon-dev libwayland-dev libdecor-0-dev \
    libegl1-mesa-dev libgl1-mesa-dev libgles2-mesa-dev libdrm-dev libgbm-dev \
    libasound2-dev libpulse-dev libdbus-1-dev libudev-dev
```

## Building and running

**Windows**

```
generate.bat -open     # creates build/buz_engine.slnx and opens it
```

Press F5 in Visual Studio. From the command line: `build.bat` then `run.bat`
(add `-release` to either for an optimized build).

**Linux**

```
./generate.sh          # configures build/ with Ninja
./build.sh             # add -release for an optimized build
./run.sh               # add -release to run the optimized build
```

## Sharing your game

```
package.bat -game=name     # Windows: package/name-windows.zip
./package.sh -game=name    # Linux: package/name-linux.tar.gz
```

Add `-web` for a version that runs in the browser.

## Graphics api

OpenGL is the default. To draw with DirectX 12 (Windows) or Vulkan (Linux),
generate with its preset, then build as usual; plain `generate` switches back:

```
generate.bat vs2026-d3d12
./generate.sh linux-vulkan
```

## Your game

`source/games/sample_2d` is a tiny "catch the ball" game and the startup
project. Read `sample_2d_game.cpp` from top to bottom: that is the whole game.

## Folder structure

| folder | what is in it |
|---|---|
| `content/` | the files games load (textures, fonts, sounds, models); copied next to the executable on every build |
| `shaders/` | the hlsl shaders, compiled on every build |
| `source/games/` | your games |
| `source/engine/` | the engine, one folder per module |
| `source/tools/` | the shader compiler the build uses |
| `source/third_party/` | libraries the engine uses |
| `build/` | generated by the generate script, safe to delete |
