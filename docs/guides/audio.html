    The engine plays sound effects and music through buz::audio, a thin layer over miniaudio.

    Paths are relative to the content folder, like textures. .wav, .mp3 and .flac files work.

    Unlike textures and models, sounds have no loading step: you play a file by its path. The first time a file plays, the engine reads it and decodes it completely, and it keeps the decoded sound, so playing the same file again doesn't read it from disk a second time. That first play has to wait for the file, which you can notice with a long piece of music.

    function what it does
    buz::audio::play_soundplays a sound once; the same sound can overlap itself (rapid gun shots)
    buz::audio::play_musicstarts the background music, replacing what was playing; it loops unless you pass buz::looping::no
    buz::audio::stop_musicstops the music
    buz::audio::set_master_volumethe volume of everything; 1 is the default

    play_sound and play_music take an optional volume: 1 plays the file as it is, 0.5 half as loud.

    On a computer without an audio device (a build server, say) the engine plays nothing and the game still runs.

    Choosing a file format#

    Use .wav for short effects: they start instantly. Use .mp3 or .flac for music: the files are much smaller. They take longer to decode, so a long track can take a moment to start the first time it plays.
