    The engine deliberately leaves out a few systems that games need, such as a 2D camera, sprite animation and collision, so that you build them yourself. The guided experiences are the exercises for those systems. Each exercise names the building blocks the engine does give you, explains the problem, and walks you through a solution one step at a time.

    The steps use pseudocode: it shows the structure and the math, but it is not C++ and it does not compile. Turning it into a class of your own is the exercise. The C++ snippets are there to show what the engine already does.

    Levels#

    Every exercise ends with a checklist in three levels: basic, intermediate and hard. Each level builds on the one before, so make the basic level work first.

    The exercises#

    2D

    • A 2D camera : build a scrolling 2D camera
    • Sprite animation : build a sprite-animation helper
    • Sprite batching : draw thousands of sprites with a handful of draw calls

    3D

    • An animation player : play keyframe clips with looping and blending
    • Collision : walls, rays, line of sight and view cones
    • An asset cache : load every model once, however often it is used
    • A radar : show the guards around the player on a minimap in the hud
