    The core module holds the small helpers that most games use sooner or later: math, rectangles, timers, random numbers and noise.

    Math (core/math.h)#

    The engine uses glm under buz names: buz::vec2, buz::vec3, buz::vec4, buz::mat4, ... These are aliases of the glm types, so every glm function works on them directly, and the most used ones are available as buz:: too:

    Colors are buz::color: four floats r, g, b, a in [0, 1], defaulting to white.

    Random numbers (core/random.h)#

    The random numbers come from a formula: each number is computed from the one before it, starting from a seed, so the same seed always gives the same sequence. buz::set_random_seed sets the seed. Without it the generator starts from the same fixed seed, so every run of your game gets the same numbers. If every run should play differently, seed it with something that changes, such as the current time.

    Noise (core/noise.h)#

    Smooth noise for procedural content: terrain heights, cloud patterns, camera shake, wobbly movement. Unlike random_float, it has no state; the same coordinates always return the same value, and nearby coordinates return similar values:

    noise_2d and noise_3d return values roughly in [-1, 1]. Remap them with * 0.5f + 0.5f when you need [0, 1] (see the procedural texture example in Textures & fonts).
