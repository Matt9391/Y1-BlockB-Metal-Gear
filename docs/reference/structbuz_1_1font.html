Detailed Description

A fixed-grid bitmap font: one atlas texture holding every character in a regular grid, in ascii order.

All glyph data is in the atlas image (content/shared/fonts/); this struct only describes the grid so draw_text can find each character:

buz::font font;
font.atlas = buz::load_texture(engine, "shared/fonts/font_8x8.png");
renderer.draw_text(font, "hello", { 20.0f, 20.0f }, 16.0f);
