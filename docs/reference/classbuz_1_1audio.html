Detailed Description

Plays sound effects and music with miniaudio (source/third_party/miniaudio). Supports .wav, .mp3 and .flac files.

The engine owns one instance (engine::get_audio). Paths are relative to the content folder, with / between folders:

audio.play_music("my_game/music/theme.mp3", buz::looping::yes);
audio.play_sound("my_game/sounds/jump.wav");
buz::audio::audio

Plays through the engine's audio device; only the engine has one to pass in.

When the computer has no audio device, every call does nothing, so the game still runs.
