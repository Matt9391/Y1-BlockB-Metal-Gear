13 /// @brief The base class of buz::game_2d and buz::game_3d: a game derives
14 /// from one of those two, depending on whether its world is 2D or 3D.
15 ///
16 /// Every game has two renderers. The world renderer draws the level and
17 /// belongs to game_2d (a world_renderer_2d) or game_3d (a
18 /// world_renderer_3d). The screen renderer draws the hud on top of it in
19 /// window pixels and belongs to this class. A game reaches each renderer
20 /// only in the function that gets it: on_render_world and
21 /// on_render_screen.
22 ///
