7// The engine uses glm (source/third_party/glm) for its math: a battle tested,
8// header-only library that mirrors the vector math you write in shaders. This
9// header gives the glm types buz names and adds the 2D projection the engine
10// itself needs. Game code only includes "core/math.h" and works with the buz::
11// names. The math of your game (the camera, transforms, interpolation) is
12// yours to write.

70 /// @brief Builds an orthographic projection for 2D rendering.
71 ///
72 /// Maps pixel coordinates to normalized device coordinates, with the
73 /// origin (0, 0) in the top-left corner of the screen and the y axis
74 /// pointing down (like most 2D drawing APIs).
75 ///
76 /// Note on conventions: the engine follows glm, so matrices are stored
77 /// column-major (m[column][row]) and positions are column vectors that
78 /// are transformed as v' = M * v. The translation lives in the last
79 /// column of the matrix.
80 ///
81 /// @param width Width of the render area in pixels.
82 /// @param height Height of the render area in pixels.
83 /// @return Orthographic projection matrix.
