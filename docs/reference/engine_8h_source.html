23 ///
24 /// Create the engine before the game: the game needs the engine to load
25 /// its textures, so it takes the engine in its constructor. C++ destroys
26 /// local variables in reverse order, so the game, and every texture and
27 /// mesh it holds, is gone before the engine shuts the graphics card down.
28 /// @code{.cpp}
29 /// int main(int argc, char** argv)
