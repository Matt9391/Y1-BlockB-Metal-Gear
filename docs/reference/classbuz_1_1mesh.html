Detailed Description

Triangles in gpu memory, ready to be drawn with world_renderer_3d::draw.

Create one with create_mesh from vertices and indices, or load one with load_mesh (both in asset_management/model_loading.h). Like textures, meshes are handed out as a std::shared_ptr: the mesh lives as long as anything holds it.
