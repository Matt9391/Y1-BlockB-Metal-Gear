Detailed Description

Which shaders draw a world_renderer_3d's meshes, and how they filter textures. The defaults are the built-in shaders, shaders/diffuse_vs.hlsl and shaders/diffuse_ps.hlsl. A shader is named by its file name without .hlsl; put your own next to them in /shaders. Your shaders get the same vertices and constants as the diffuse ones, so start from a copy of those, which declare the first two of these:

  • per draw, at register(b0): world (object space to world space), the rows of the normal matrix, and the material's lit, alpha_cutoff and base_color
  • per frame, at register(b2): the camera's view_projection (world space to the screen) and camera_position (in world space)
  • at register(b1): the data you hand to world_renderer_3d::set_shader_data
