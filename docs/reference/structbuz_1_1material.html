Detailed Description

How a mesh looks: a color, optionally times a texture, lit or not, optionally with see-through holes.

These are the only options the engine's shaders read; a surface that needs anything else needs shaders of its own.

float buz::material::alpha_cutoff = 0.0f

Pixels whose alpha (texture times color) is below this are not drawn, which leaves a hole: a railing is a flat quad whose texture has alpha 0 between the bars, cut out with 0.5. The default, 0, draws every pixel, so alpha between 0 and 1 blends instead.
