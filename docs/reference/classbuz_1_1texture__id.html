Detailed Description

Names an image without loading it: an image file in the content folder, or an image inside a model file (a .glb carries its textures inside).

buz::import_model and buz::load_model fill a material's base_texture with one; buz::load_texture(engine, id) loads the image it names. Two ids are equal when their images are the same bytes, whatever file they came from: five models sharing one brick texture give five equal ids, so a cache keyed by texture_id loads the bricks once.
