Detailed Description

One node of a model, as it was named and placed in Blender.

A character made of rigid parts (the PS1 way) is a hierarchy of nodes: pelvis -> torso -> head, upper arm -> lower arm, and so on, each part a mesh that moves with its node. A level is a flat list of nodes too: walls with meshes, and empty nodes whose names mark what they are (col_* collision boxes, patrol_* points, camera_* positions).
