Detailed Description

Draws the 3D game world, through a camera.

Owned by buz::game_3d and handed to on_render_world every frame; the world is drawn in the order of your calls, and nearer surfaces hide farther ones whatever that order (there is a depth buffer).

void my_game::on_render_world(buz::engine& engine, buz::world_renderer_3d& world)
{
world.draw_box({ 0.0f, 0.5f, 0.0f }, { 1.0f, 1.0f, 1.0f }, m_crate_material);
world.draw(*m_snake_mesh, m_snake_material, *m_snake_texture, m_snake_transform);
}

◆ set_shader_data()

void buz::world_renderer_3d::set_shader_data ( std::span< const std::byte > data)

Hands data to your own mesh shaders (see buz::set_surface_shading), for every draw that follows, in this frame and the next ones, until you set it again. The shaders read it as a cbuffer at register(b1):

[[vk::binding(0, 2)]] cbuffer shader_data : register(b1)
{
float4 fog_color;
float fog_distance;
};

The struct you pass and the cbuffer must agree on the layout: hlsl packs the members in rows of four floats, and a member never straddles two rows. The built-in shaders don't read it.

The engine fills the other two blocks: the draw's world matrix, normal matrix, lit, alpha_cutoff and base_color at register(b0), and the camera's view_projection and camera_position at register(b2), with [[vk::binding(0, 3)]] (buz::surface_shading lists them; the diffuse shaders declare them).

Parameters
dataAt most 4096 bytes; a copy is kept.
