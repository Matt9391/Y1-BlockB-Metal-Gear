35 /// @brief Repairs for models that look right in the viewer they came from
36 /// but not in the engine, typically files saved out of a web viewer
37 /// (three.js and the like), which draws both sides of every triangle and
38 /// repeats textures. Everything is off by default: a model made in
39 /// Blender needs none of it.
40 /// @code{.cpp}
41 /// buz::load_model(engine, "my_game/models/soldier.glb", { .normals = buz::orient_normals::yes, .uvs = buz::wrap_uvs::yes });
42 /// @endcode
43 struct model_import_options
44 {
45 /// @brief Turns around every vertex normal that points against the
46 /// triangles it belongs to. The triangles' winding (counter clockwise
47 /// seen from the front) is taken as the truth, so what culling keeps
48 /// and how it is lit agree. Fixes a model that draws the right faces
49 /// but is lit as if from behind (dark, light from the wrong side).
50 /// It does not fix a model whose winding itself is reversed (the
51 /// outside culled away): that needs fixing in Blender.
52 orient_normals normals = orient_normals::no;
53
54 /// @brief Moves each primitive's texture coordinates by whole numbers
55 /// so they start in 0..1. The engine clamps textures at their edges,
56 /// so coordinates in, say, -1..0 all read the edge pixels (streaks);
57 /// a viewer that repeats textures showed the same texels this picks.
58 wrap_uvs uvs = wrap_uvs::no;
59 };

76 /// @brief Loads a glTF model (.gltf or .glb) from the content folder,
77 /// with its parts, their hierarchy and its animations:
78 /// @code{.cpp}

80 /// @endcode
81 ///
82 /// Every call loads the file again and uploads new meshes: loading a
83 /// model once and reusing it is up to you. Textures are not loaded: each

86 /// @param engine The engine, which owns the graphics card.
87 /// @param content_relative_path Model file, relative to the content folder, with / between folders.
88 /// @param options Repairs to apply while reading; none by default.
89 /// @return The model, or nothing when it could not be loaded (the reason is logged).
