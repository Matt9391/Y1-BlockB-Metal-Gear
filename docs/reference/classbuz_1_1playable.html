Detailed Description

What engine::run runs. Every frame the engine calls update, then render_world, then render_screen.

Derive your game from buz::game_2d or buz::game_3d, not from this. Those come from the game_framework module, whose buz::game implements playable; that is all the engine knows about them. A different way of structuring games, an entity component system for example, can take the game_framework module's place by implementing playable itself, without changes to the engine.
