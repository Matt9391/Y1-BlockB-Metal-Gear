Detailed Description

The base class of a game with a 3D world: derive your game from it.

It owns the game's world renderer, a buz::world_renderer_3d, and hands it to on_render_world every frame; the screen renderer comes from buz::game. Load what the game needs in its constructor, which gets the engine, and let the destructor (or the members' own) clean up. Override the functions you need:

class my_game : public buz::game_3d
{
public:
explicit my_game(buz::engine& engine); // load models here
protected:
void on_update(buz::engine& engine, float delta_seconds) override; // game logic here
void on_render_world(buz::engine& engine, buz::world_renderer_3d& world) override; // draw the level here
void on_render_screen(buz::engine& engine, buz::screen_renderer& screen) override; // draw the hud here
};
