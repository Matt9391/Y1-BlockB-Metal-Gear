Detailed Description

Owns all engine systems and runs the main loop.

The engine comes first, the game second: the game needs the engine to load its textures, so it takes it in its constructor. C++ destroys local variables in reverse order, so the game, and every texture and mesh it holds, is gone before the engine shuts the graphics card down.

int main(int argc, char** argv)
{
buz::engine engine(argc, argv, { .window_title = "my game" });
my_game game(engine);
return engine.run(game);
}

Opens the window and starts every system. When that is impossible (no graphics card that can run the game, say) the engine stops with an error message: nothing can run without them.

The settings on the command line (see engine_settings) win over the game's, so they can change without rebuilding.
