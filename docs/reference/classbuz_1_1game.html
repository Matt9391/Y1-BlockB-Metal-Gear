Detailed Description

The base class of buz::game_2d and buz::game_3d: a game derives from one of those two, depending on whether its world is 2D or 3D.

Every game has two renderers. The world renderer draws the level and belongs to game_2d (a world_renderer_2d) or game_3d (a world_renderer_3d). The screen renderer draws the hud on top of it in window pixels and belongs to this class. A game reaches each renderer only in the function that gets it: on_render_world and on_render_screen.

The engine owns the main loop and calls update, render_world and render_screen every frame; they call the on_ functions a game overrides.
