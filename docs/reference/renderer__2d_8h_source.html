40 /// @brief The drawing functions shared by world_renderer_2d and
41 /// screen_renderer.
42 ///
43 /// Sprites, rectangles, lines and text are quads: a single unit quad
44 /// lives in gpu memory and each of those draws renders it with its own
45 /// transformation, texture and tint color. Circles and triangles are
46 /// built from triangles on the cpu instead. Positions are in pixels (or
47 /// world units, once the world has a camera) with the y axis pointing
48 /// down.

54 //----------------------------------------------------------

57 /// @param position Position of the sprite center.
58 /// @param size Width and height of the sprite.
59 /// @param rotation_radians Clockwise rotation around the sprite center.
60 /// @param tint Color multiplied with the texture (white leaves the texture untouched).
61 void draw_sprite(const texture& sprite_texture, vec2 position, vec2 size, float rotation_radians = 0.0f, color tint = color{});
62
63 //----------------------------------------------------------

68 /// @param source_rect Part of the texture to draw, in texture pixels.

72 /// @param tint Color multiplied with the texture (white leaves the texture untouched).

117 //----------------------------------------------------------
118 /// @brief Draws many sprites of the same texture in one go.
119 ///
120 /// Every draw_sprite call is a separate draw call: a separate
121 /// request to the gpu, each with a small fixed cost. A tile map of a
122 /// few thousand tiles drawn with draw_sprite spends most of the frame
123 /// on those requests (the stats overlay shows the count). This function
124 /// draws all its sprites with a single draw call instead.
125 ///
126 /// It only takes sprites that share one texture, so grouping your
127 /// sprites by texture is up to you: that is what a sprite batcher
128 /// does.
129 /// @param sprite_texture Texture all instances are drawn with (a
130 /// sprite sheet, typically).
131 /// @param instances The sprites.
132 void draw_sprite_instances(const texture& sprite_texture, std::span<const sprite_instance> instances);
133
134 //----------------------------------------------------------

136 public:
137 //----------------------------------------------------------

140 /// @param text_font Font to draw the text with.
141 /// @param text The text to draw.
142 /// @param position Top-left corner of the first character.
143 /// @param pixel_height Height of one character.
144 /// @param tint Color of the text.
145 void draw_text(const font& text_font, std::string_view text, vec2 position, float pixel_height, color tint = color{});
