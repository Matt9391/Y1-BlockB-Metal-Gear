orient_normals normals = orient_normals::no
 Turns around every vertex normal that points against the triangles it belongs to. The triangles' winding (counter clockwise seen from the front) is taken as the truth, so what culling keeps and how it is lit agree. Fixes a model that draws the right faces but is lit as if from behind (dark, light from the wrong side). It does not fix a model whose winding itself is reversed (the outside culled away): that needs fixing in Blender.
wrap_uvs uvs = wrap_uvs::no
 Moves each primitive's texture coordinates by whole numbers so they start in 0..1. The engine clamps textures at their edges, so coordinates in, say, -1..0 all read the edge pixels (streaks); a viewer that repeats textures showed the same texels this picks.

Detailed Description

Repairs for models that look right in the viewer they came from but not in the engine, typically files saved out of a web viewer (three.js and the like), which draws both sides of every triangle and repeats textures. Everything is off by default: a model made in Blender needs none of it.

buz::load_model(engine, "my_game/models/soldier.glb", { .normals = buz::orient_normals::yes, .uvs = buz::wrap_uvs::yes });
