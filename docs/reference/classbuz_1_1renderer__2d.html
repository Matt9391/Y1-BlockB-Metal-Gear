Detailed Description

The drawing functions shared by world_renderer_2d and screen_renderer.

All geometry is a quad: a single unit quad lives in gpu memory and every draw call renders it with its own transformation, texture and tint color. Positions are in pixels (or world units, once the world has a camera) with the y axis pointing down.

◆ draw_sprite_instances()

void buz::renderer_2d::draw_sprite_instances ( const texture & sprite_texture,
std::span< const sprite_instance > instances )

Draws many sprites of the same texture in one go.

Every draw_sprite call is a separate draw call: a separate request to the gpu, each with a small fixed cost. A tile map of a few thousand tiles drawn with draw_sprite spends most of the frame on those requests (the stats overlay shows the count). This function draws all its sprites with a single draw call instead.

It only takes sprites that share one texture, so grouping your sprites by texture is up to you: that is what a sprite batcher does.

Parameters
sprite_textureTexture all instances are drawn with (a sprite sheet, typically).
instancesThe sprites.
