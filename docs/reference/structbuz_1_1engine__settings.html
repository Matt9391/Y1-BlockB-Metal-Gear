Detailed Description

Settings the engine starts with.

Set the ones you want to change and keep the rest; designated initializers read well for that:

buz::engine engine(argc, argv, { .window_title = "my game", .sampler_filter = buz::texture_filter::nearest });
buz::engine
Owns all engine systems and runs the main loop.

buz::texture_filter::nearest
@ nearest

The most common ones can also be changed at launch, without rebuilding; the command line wins over the game's settings:

setting example
-window_width, -window_height -window_width=1920
-window_title -window_title=Demo
-gpu -gpu=lowest, or -gpu=software for a software rasterizer
-screenshot, -screenshot_frame -screenshot=frame.png -screenshot_frame=300

A command line setting the engine does not recognize is logged as a warning, so a typo is reported instead of being ignored.
